## Architecture Layers

Five-layer architecture for maintainability and hot-path performance.

| Layer | Name | Rules |
|-------|------|-------|
| L0 | Core | Types only (dataclasses, enums, type aliases). No I/O, no logic. |
| L1 | Storage | File I/O (`store.py`, `index.py`). Read/write JSON files. |
| L2 | Domain Logic | Pure Python. Stateless methods, no file I/O. |
| L3 | Integration | Discord bot, handlers, formatters. Orchestrates L0–L2. |
| L4 | Cron Jobs | Standalone scripts. Read L1–L2, write cache files for L3. |

**Key rule:** Layer N may import Layer N and below. Never Layer N+1 or higher.

**Hot path** (Discord message → pi subprocess → response) uses only L3 + cache files
(pre-generated by L4 cron jobs).

**Layer checker:** `scripts/check_layer_imports.py` audits all Python files.
Run it manually, in CI, or as a pre-commit hook.

See `REFACTOR_PLAN.md` for full rationale.
